# 💌 Doce papelitos

Página personal hecha en **HTML, CSS y JavaScript puro** — un solo archivo `index.html`, sin frameworks ni dependencias.

## 🧱 Estructura

```
Pagina-De-Amor/
└── index.html   # Página completa (HTML + CSS + JS)
```

## 🚀 Cómo verla

Abre `index.html` con doble clic en cualquier navegador, o publícala gratis con **GitHub Pages** (Settings → Pages → rama `main`).

## 🛠️ Stack

HTML · CSS · JavaScript
